This repo contains testing scripts and test data for https://github.com/TongmingLAIC/AppForge. 

The generated app code are compiled through *compiler/build.py* and then tested through *evaluate_app.py*. The fuzzing process is done in *fuzzing.sh*.

Testing scripts are stored in json format. For example, test data for testing app **Chess_Clock** are stored in *tasks/Chess_Clock/functional_tests/*.
